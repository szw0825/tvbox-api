# TVBox API 配置

这是一个 TVBox 视频聚合配置文件仓库。

## 📺 配置文件

**文件名：** `vodtv.json`

### 订阅地址

选择以下任一地址使用：

#### 方案 1：原生 GitHub Raw 链接（推荐稳定性）
```
https://raw.githubusercontent.com/szw0825/tvbox-api/main/vodtv.json
```

#### 方案 2：jsDelivr CDN 加速（全球访问）
```
https://cdn.jsdelivr.net/gh/szw0825/tvbox-api@main/vodtv.json
```

#### 方案 3：ghfast 加速（国内访问）
```
https://ghfast.top/https://raw.githubusercontent.com/szw0825/tvbox-api/main/vodtv.json
```

---

## 🚀 使用建议

| 使用场景 | 推荐地址 |
|---------|--------|
| 🌍 国外用户 | 方案 2 (jsDelivr) |
| 🇨🇳 国内用户 | 方案 3 (ghfast) |
| ⚡ 稳定优先 | 方案 1 (Raw) |

---

## 📋 配置说明

配置文件包含：
- **17 个视频源**（包括影视狗、虎牙、卧龙、极速等）
- **3 个直播源**（牛播一、mytv、平台直播）
- **壁纸和 Logo 资源**
